and be green first.

  ruff findings of trivial shape (`E401` multi-import lines, `E702` semicolons, `E731`
  lambda assignment, `F401` unused imports, `E741` ambiguous names) plus 2 ty
  `unresolved-import` diagnostics, all mechanically fixable. An `extend-exclude` entry is
  reserved in this project for notebook-style probe directories
  (`analysis/tilt_study/probes`), which these are not: TAGFIX-08 requires them to skip
  cleanly when the clone is absent, i.e. they are maintained code.
- **D-03 fallback scope (flagged planner interpretation).** The `game_positions` fallback
  runs when `pv_blob is None`. It does NOT run for the `[]` sentinel, because D-04 states
  the `[]`-sentinel behaviour is unchanged and the current `[]` semantics is "gate skipped,
  never suppressed, FINAL case". The alternative reading (apply the floor to `[]` too) is
  one conditional away and is recorded here so the developer can flip it; plan 06's dev
  smoke reports the `[]`-row count so the size of the exposure is visible.
- **Unresolved edge (TAGFIX-06).** The deterministic edge probe classified TAGFIX-06 as
  `unclassified`. It is carried forward as `unresolved`, NOT dismissed. The planner's
  assumption is that the only edge worth pinning is the ply-0 / malformed-previous-SAN
  fallback on the D-09 board build, which plan 04 covers with an explicit truth and test.
  If the developer sees a second edge here, plan 04 is the place to add it.
- **`workflow.human_verify_mode = end-of-phase`.** The operator's ~20-row spot check
  (D-13) is emitted as a `<verify><human-check>` on task 2 rather than a mid-flight

  human still sees it BEFORE any prod write, because plan 07's deploy gate is a
