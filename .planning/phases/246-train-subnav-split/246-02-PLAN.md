<objective>
Turn `/train` into a layout with URL-routed tabs and move the session state up, so Leaderboard is a real tab that neither creates a session nor loads the engine.

Purpose: this is the state-ownership heart of the phase. `TrainPage` owns session state, loop flags and the grading Worker, and `/train/*` already routes every sub-path to it. One hook with a one-way latch gives the layout synchronous knowledge of the immersive state, removes the restored-reveal flash, and keeps a single Worker per page visit, which matters against iOS's tight wasm reservation budget.

Output: `useTrainLoop`, `parseTrainRoute`, `TrainSubnav` and a Leaderboard tab. This plan does not edit `TrainStartScreen`. Plan 246-08 changes what the landing itself mounts: the `isVisible` gate, the medal host and the leaderboard card coming off Today. Until it lands, Today still shows the card and a hidden landing still runs its one-shot effects, which only matters on this phase branch. Archive arrives in plan 246-05: until then `parseTrainRoute` does not know its path, so `/train/archive` redirects to Today and only two tabs exist. Every intermediate state stays coherent.
</objective>

<design_notes>
**One correction to 246-RESEARCH.md.** Q3 says the three `startSession` call sites all stay reachable only from Today. That stops being true once the landing stays mounted and hidden. `TrainScheduleSettings` debounces saves by 600 ms, so an edit followed by a quick tab switch fires `onSaved` while Leaderboard is showing, and passing `startSession` straight through would POST there, against D-06. `requestSessionReread` fixes this: it only sets the same `sessionStale` state that Pitfall 1 needs, and one effect does the re-read when `isToday` is true. It must stay stable, because `onSaved` is in the dependency list of the settings save effect, and a changing identity would re-run that effect and double-save while a save is in flight.

**Choices adopted from RESEARCH under Claude's Discretion:** a layout-level latch rather than moving the hooks to a Today route (the seed's wording, which CONTEXT left open); one responsive `TabsList` rather than Library's duplicated pair, because a duplicated pair would double-mount the session and medal hosts; plain-div panels rather than `TabsContent`, which applies `flex-1 text-sm` to everything inside. The trade-off is a dangling `aria-controls` from Radix triggers, which is harmless.

**Spacing under the tabs:** `mt-4` on every panel. On a phone that gives the 8px page padding + 40px tab bar + 16px gap, which is the +40px D-16 accepted over the old 24px top padding.
</design_notes>
