<objective>
Make the in-process server-pool drain re-walk tier-4 games blob-only (D-12): a `TIER_BLOB_BACKFILL` claim goes to a
new `_tier4_blob_drain_tick` that shares plan 02's apply core with `/flaw-blob-submit`, so `eval_cp`, `eval_mate`,
the flaw set and `game_best_moves` stay untouched (protects D-03, D-05, D-06).

Then make the mixed worker fleet provably harmless for re-walk games (D-15): version-2 workers keep getting 204 on
every lane that could reach a re-walk game, the entry lane they still use cannot touch one, and `/atomic-lease` never
serves a tier-4/4b claim to any client.

Purpose: prod runs `EVAL_AUTO_DRAIN_ENABLED=true` and the benchmark `:8001` backend too; today a tier-4 claim in the
server pool fully re-evaluates the game, which would rewrite evals and reshuffle flaw sets for every game the feeder
re-opens. The owner cannot update all workers soon (D-15), so the re-walk must run safely next to version-2 workers.
Output: modified `eval_drain.py` and `eval_remote.py`, a D-12 test class and a D-15 test class, both mutation-checked.
</objective>
