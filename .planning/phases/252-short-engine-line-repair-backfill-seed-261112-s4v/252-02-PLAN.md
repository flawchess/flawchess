<objective>
Teach the tier-4 flaw-blob lane per-line NULLs (D-03): lease, sentinel and submit only the NULL line of a flaw,
write it fill-NULL-only, re-derive only that line's four tag columns, and keep `games.blobs_completed_at` NULL until
both lines are filled. Extract the submit apply core into `eval_apply.py` so the server-pool drain (plan 03, D-12)
uses the identical path.

Purpose: the re-walk (plans 04, 07, 08) NULLs only the repaired line; without this plan the lane would ignore a
missed-only NULL and would overwrite the untouched line on submit.
Output: modified `eval_apply.py` and `eval_remote.py`, new endpoint and unit tests.
</objective>
