<objective>
Put the Library Stats flaw snapshot on the recent sample, end to end: one ranked window statement in
the repository (most recent 1000 games per time control within 36 months, or within the selected
recency period), a pure window summary in the service, GET /library/flaw-comparison computed on it
with the window metadata in the response, and the Flaw Stats basis line that states the sample.

Purpose: CONTEXT D-03 to D-08, D-10 to D-13, D-15 for the flaw path; D-02 guarded by a test. The
facepalm and tactic endpoints move onto the same window in plan 02; the quiet-TC page state, the
timeline caption, the default-TC fallback and the popover wording are plan 03.

Output: the window statement and summary, the windowed `get_flaw_comparison`, the new schema fields
on both stacks, the basis line, the seed migration of the comparison tests (every seeded game now has
a `played_at`, every flaw-comparison service call passes `now_utc`), and the window test file.

Task order note: Task 1 makes `now_utc` a required keyword of `get_flaw_comparison`, so the 28
existing `get_flaw_comparison` calls in `tests/services/test_flaw_comparison.py` fail with a missing
keyword until Task 2 migrates them. Task 1's verify therefore runs the router, frontend and `app/`
type checks only; Task 2's verify runs the full comparison test files and `ty` over `tests/`. Run
Task 2 directly after Task 1.

Recorded assumptions (Claude's discretion, flagged for UAT, none blocks):
- Clock: the window bound is computed in Python from `dev_now_utc` (`months_before(now_utc, 36)`),
  not SQL `NOW()`; nothing persisted has to match it (the Endgames exception does not apply).
- Schema: the metadata rides on `FlawComparisonTc` (`sample_since`, `cap_reached`,
  `history_analyzed_n`) and `FlawComparisonResponse` (`recency_filtered`, `window_months`,
  `games_cap`); `analyzed_n` / `total_n` keep their names and become windowed, so every existing
  reader (gate slot, coverage hint, popover basis, default TC) moves to windowed numbers for free.
- `sample_since` is the date of the oldest game in the window; the basis line shows it only at the cap.
- A custom range with only `to_date` counts as an explicit recency filter (research A4).
- Wording (D-13 allows polish, structure locked): the filter phrase sits right after "games"; with
  both a recency filter and another filter it reads "in the selected period and the current
  filters". The fresh-import line ("0 of N games analyzed in the current filters.") keeps its
  unwindowed text (research Open Question 2).
- Offered TCs stay "TCs with an analyzed game in the unwindowed filtered set" (today's rule), so a
  quiet TC keeps its place on the switch (D-15).
</objective>
