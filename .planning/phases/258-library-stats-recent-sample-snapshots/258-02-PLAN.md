<objective>
Move the facepalm and tactic snapshot endpoints onto the recent window that plan 01 built, so the
three "now" sections of the Stats tab describe one game set.

Purpose: CONTEXT D-06 (one shared windowed set), D-10 (facepalm keeps its own endpoint with JIT off,
gates and the low-coverage rule unchanged but applied to the window), D-15 (quiet TCs come only from
the flaw list), D-03 / D-04 on the two remaining routes.

Output: windowed `get_facepalm_comparison` and `get_tactic_comparison`, `now_utc` on both routes,
the facepalm and tactic call sites in the tests migrated, and the window tests of both paths.

Recorded assumptions (Claude's discretion, flagged for UAT, none blocks):
- The facepalm list rule changes from "TCs with an analyzed anchor game" to "TCs with a window game":
  a TC offered by the flaw list from history whose recent games are all unanalyzed would otherwise
  leave the Facepalm tile on its loading skeleton.
- The tactic path drops its separate unwindowed blob-gated count: the window rows already carry the
  same gate (`tactic_ready` = analyzed and blobs done), so the statement count goes down by one.
- JIT: the flaw and tactic paths do not switch JIT off; plan 04's prod EXPLAIN decides (research
  Pitfall 4: measure, do not guess).
</objective>
