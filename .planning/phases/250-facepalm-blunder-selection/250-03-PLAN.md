<objective>
Swap the blunder-check candidate predicate from the 249 D-06 findability pairs onto the stored facepalm score
(D-09, D-01) and make the no-repeat rule permanent (D-17), plus the qualifying-blunder EXISTS option the window mix
(plan 06) uses for blunder slots.

Purpose: one named threshold decides which blunders the drill serves; a blunder is never served twice.
Output: repository, pure judge and composer updated; the 249 tests that asserted D-06 or the false-alarm exception
rewritten or inverted. No frontend changes: the API schema (`app/schemas/blunder_check.py`) and
`frontend/src/types/blunderCheck.ts` carry no Maia field and are untouched.
</objective>
