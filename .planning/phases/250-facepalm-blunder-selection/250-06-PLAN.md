<objective>
Change where windows come from (D-12..D-16): one third herrings, one third own blunders, one third foreign blunders
at the user's level, herrings split own / foreign like blunders, own slots falling back to foreign, and a level that
reflects the user's most-played time control.

Purpose: removes the own-game giveaway and gives users without analysed games a full drill.
Output: rules.py draws, selection.py composition by origin, the D-14 level helper and repository filter, tests.
No API or frontend change: `is_own` already travels end to end (249), so no frontend changes in this plan.

<assumption_delta_decision>
Noun that is primary: the window's source game, with `blunder_check_windows.is_own` recording whether it is the
drilling user's game. Decision: no-change. 249 already generalised the identity (own windows and foreign windows share
one table keyed by user_id + game_id with is_own), and D-12..D-16 decide the mix and the fallback, so no identity-model
gap remains. Optional invariant test included below: every composed window's is_own equals (game owner == caller).
</assumption_delta_decision>
</objective>
