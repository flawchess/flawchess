<objective>
Draw the route dot inside the Library and Openings sections (D-03): on the Import, Library Stats and Openings Stats
subtabs, and on the Openings played-as and filters controls, which become route steps (D-07). Using a control records
its step (D-13). The old Openings hint chain and its bookmarks dot go away.

Purpose: plan 255-02 moves the dot off the nav item once the user is in the section; this plan gives it the place it
moves to, so the one dot is never lost inside Library or Openings.
Output: subtab dots on both Library tab lists and both Openings tab lists, route-driven played-as and filters dots on
desktop and mobile, the completion writes in the existing handlers, and the trimmed `useSidebarState`.

Spec-less probe: no SPEC.md and no requirement IDs, so the spec-less probe fallback is skipped by choice; coverage is
the D-01..D-22 audit.
</objective>
