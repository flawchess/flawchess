<objective>
Add the refutation-only backfill mode (D-10) on the shared scorer: select base-stamped games without the refutation
stamp, score only user-side blunders from a PGN replay, write the two columns plus the new stamp, and report
progress and reasons per mode. This is the only catch-up path for the refutation pair, re-runnable like 247's.

Purpose: about 2.3M user-side blunders on prod need the pair without re-scoring all 7.6M flaws; the mode keeps the
prod backfill at about one inference per user blunder.
Output: mode-aware scorer and backfill script, tests with mutation proofs, a dev smoke.

ORCHESTRATION NOTE: run in the phase worktree (see plan 01). Commit with plain `git commit`, trailers supplied by the
orchestrator; never the GSD commit helper. Dev smokes target `--db dev` only; never `--db prod` in this plan.
docs/dev-tooling.md is updated by plan 06 (ship), not here.
