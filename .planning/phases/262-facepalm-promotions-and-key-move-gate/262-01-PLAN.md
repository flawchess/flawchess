go-forward hook, the line pass, the features tool and the new promotion pass (plan 04) all reach this rule through
`facepalm_material_inputs`, so the rule lives in one place.

Output: `_promotion_gain` added inside `_victim_value`, the static exchange reading `_victim_value`, new per-depth and
stored-pair tests, four re-derived line fixtures.

Spec-less probe fallback: skipped (the phase has no requirement IDs to probe); recorded here as a visible choice.
</objective>
