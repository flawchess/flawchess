<objective>
Make the Node harness able to observe Maia/Stockfish overlap faithfully before any continuous-dispatch code exists:
move harness Maia off the event loop into a worker thread (D-18), and give the Node Stockfish pool the browser's
abort semantics plus a quiescence hook (D-09, N-2).

Purpose: research measured that main-thread wasm Maia blocks the event loop for about 94 ms per inference and that
FIFO-chained inferences let zero timer ticks through a 373 ms burst, so Stockfish completions would be starved in
continuous mode; and the Node pools ignore the abort signal, so D-09's cancellation would never happen in Node and
stale grades would run into the next position's timing window. Both would make the Node gate measure a crippled
continuous mode.
Output: a worker-backed Maia session behind the unchanged `createMaiaSession` surface, an abort-aware pool with
`whenIdle()`, and two check scripts that prove both, each with a discriminating negative control.
</objective>
