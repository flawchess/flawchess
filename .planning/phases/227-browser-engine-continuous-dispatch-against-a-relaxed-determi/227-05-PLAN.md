<objective>
Give the calibration harness algorithm parity with the app's dispatch flag (D-14) and make A0/A1 sweeps impossible
to mix (D-15), then pin the determinism check to round mode and assert app/harness parity.

Purpose: D-15's powered calibration compares A0 (round) and A1 (continuous) from the same checkout in the same
session; persona calibration and the bot-strength curves must run the dispatch mode the app ships; and a resumed sweep
that silently mixed modes would corrupt the comparison.
Output: harness flag + ledger column + resume refusal, supervisor env hook, updated schema and determinism checks.
</objective>
