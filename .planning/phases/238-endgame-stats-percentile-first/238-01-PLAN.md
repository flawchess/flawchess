<objective>
Build the backend core of the percentile-first Endgame Stats tab: a filter-free `GET /api/endgames/ranked-stats` endpoint that computes all 11 peer-ranked metric values on read from the canonical ranked slice, per time control, with a rank status per metric and the WDL components that make the big number, its WDL bar and the percentile describe the same games.

Purpose: SEED-196 decision 2 (D-00b) and D-07. Today the card shows a filtered whole-history value while the percentile ranks a different (ranked) value. Research found five definitional divergences between the Python aggregators and the Stage A/B CTEs, so the gate is a DB-backed numeric parity test, not code review. This plan also fixes the full response contract that the frontend plans (238-03, 238-05) and the insights plan (238-04) build against.

Output: `ranked_games_sql`, `endgame_ranked_repository.py`, `endgame_ranked_service.py`, the ranked Pydantic contract, the router endpoint, a golden byte-identity guard for the canonical builders, and the parity + status test suites.
</objective>
