<objective>
Make Shelly's endgame insights filter-independent and narrate the same ranked values the page shows (D-04). The router, the cache key and the frontend-facing report shape lose all filter plumbing; `compute_findings` consumes the ranked service from plans 238-01/02; the user prompt and system prompt are realigned and the prompt version moves to `endgame_v48` with a deliberate golden regeneration.

Purpose: after the redesign the UI shows ranked per-TC values; if Shelly kept narrating filtered whole-history numbers, her numbers would not match the page. D-04 is rated costly (insights request contract, server cache keying, frontend cache), and the owner locked it.

Output: filter-free insights router and service, `endgame_v48` prompt, regenerated golden, rewritten tests. The frontend hook change lands in plan 238-06.
</objective>
