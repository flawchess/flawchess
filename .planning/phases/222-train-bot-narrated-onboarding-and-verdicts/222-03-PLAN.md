## Post-release reading procedure (recorded for SC6)

After the phase deploys, the comparison is: open `/activity` as a superuser, set the window
to a range ending before the release date, read both shares; set the window to a range
starting at the release date, read both shares again. The all-time line on the card is the
running control. The frozen 2026-09-12 production baselines (52/123 = 42% first-session
0-solve; 26/53 = 49% second-session return) remain in
`.planning/seeds/SEED-166-train-first-session-retention.md` as the historical record.
</verification>
