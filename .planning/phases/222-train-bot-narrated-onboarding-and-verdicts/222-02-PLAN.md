<objective>
Ship the phase's only new server surface: three nullable `DateTime(timezone=True)` columns
on `train_settings`, one stamping endpoint that writes them first-write-wins, and the D-17
extension that lets a resumed or handed-off session reconstruct the score screen's recap.

Purpose: D-12/D-14 require the explanation-seen state to live on the server because the
phone handoff moves users between devices, and guests never reach any `/train/*` endpoint
so no device-local fallback exists. D-17 covers the restore path for the score bubble; the
live path is plan 06's accumulator (RESEARCH Finding C — both halves are needed).

Output: the Alembic revision, the model columns, the repository stamp function and its
three mechanical dataclass touch points, the `POST /train/onboarding/{step}` handler, the
widened `SolvedResult`, and the `scripts/reset_train_state.py` clear that makes onboarding
UAT repeatable on dev without a database reset.
</objective>
