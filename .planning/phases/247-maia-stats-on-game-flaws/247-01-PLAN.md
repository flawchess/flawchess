<objective>
Build the two Maia primitives the Phase 247 scorer stands on, and prove them on a real ORT session: the one-pass
`full_policy` helper next to `score_move` (D-04, symmetric Elo feed per D-03), the pure per-flaw stats derivation
`compute_maia_flaw_stats` (D-01, with the D-15 second-equals-best rule), the per-process ORT thread option the
backfill needs, and the deterministic `fake_full_policy` test helper every later plan's tests patch in.

Purpose: the scorer (plan 02), the remote lanes (plan 04) and the backfill (plan 05) all derive their eight column
values through exactly these functions. Splitting them into their own wave-1 plan keeps the scorer plan's tracer
within the per-plan file budget, and pins the rank/entropy/second rules with fast pure tests before any DB code
exists.
Output: `full_policy` and `start_maia(intra_op_num_threads=...)` in `app/services/maia_engine.py`, the new
`app/services/maia_flaw_stats.py`, `tests/services/maia_fakes.py`, and their tests.
</objective>
