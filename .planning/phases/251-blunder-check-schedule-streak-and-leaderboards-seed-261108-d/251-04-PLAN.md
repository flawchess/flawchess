<objective>
Make both session sizes editable at any time through PUT /train/settings, with the D-06 resize rules for an open
blunder-check session, puzzles that can be switched off, and the day completing when a size change makes it complete.

Purpose: D-04 rejected "applies from the next scheduled day", so a size change must act on today's open session and
today's streak in the same request, without ever minting a second credit or reopening a completed session.

Output: optional new settings fields with a not-both-zero validator, a settings service that orchestrates
settle-before-mutate, the BC resize, puzzles-off handling and the day-completion call, and tests for every D-06 branch.
</objective>

## Assumptions surfaced for the owner

- A4: setting blunder check to 0 marks the open session 'expired', not 'completed': the mode is simply not required
  today, and raising it again the same day composes a fresh session.
- A started-but-unended window in the "n <= ended" case stays stored (it was shown, D-01) and never gets an outcome, so it
  is excluded from the boards. Settings are edited only from the Today page, never while a drill is on screen, so this
  only follows an abandoned window.
- The puzzles slider keeps its existing in-session behaviour for sizes above 0 (an untouched session is recomposed, a
  touched one keeps its size); only the 0 case is new.

## Interface for later plans

- PUT body: `puzzles_per_session` (0..50, required as today), `blunder_check_per_session: int | None` (0..30, optional),
  `blunder_check_level: BlunderCheckLevel | None` (optional; None or absent keeps the stored value).
- GET/PUT response: adds `blunder_check_per_session: int` and `blunder_check_level: BlunderCheckLevel | None`.
