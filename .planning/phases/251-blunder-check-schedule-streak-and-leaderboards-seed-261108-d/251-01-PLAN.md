<objective>
Lay the phase's schema and give blunder-check sessions a session day that expires like a puzzle session's, end to end,
before the streak rule (plan 12) or any UI or settings work.

Purpose: D-02's both-modes rule needs to know on which local day a blunder-check session was completed, and D-01's
serve-once must survive abandoned sessions. Every writer of `blunder_check_sessions`, including the pre-existing test
fixtures, has to supply the new day the moment the NOT NULL columns land, so the schema and the dated writer ship together.

Output: one Alembic migration with all non-leaderboard schema of the phase, the phase's Train constants, blunder-check
sessions dated with the user's local day that expire, resume or show as done within their window, `complete_session`
reporting whether it moved the row, a seed helper for completed sessions on a given day, and every blunder-check test
fixture updated for the new columns.
</objective>
