<objective>
Add the Facepalm range filter and the score payload to the Library API (D-04, D-05, D-06, D-10, D-14, D-17):
two optional inclusive whole-percent params on `GET /library/flaws` and `GET /library/games`, one shared clause in
`build_flaw_filter_clauses`, the activity gate in `apply_game_filters`, and `facepalm_score` on `FlawListItem`.

Purpose: plans 02 and 03 build the filter panel and the Blunder-badge score on this contract. The contract is fixed
here so plan 02 can run in parallel: params `min_facepalm_pct` / `max_facepalm_pct` (int 0..100, inclusive, on the
floored percent scale; both omitted or 0/100 = no filter) and response field `facepalm_score: float | null` (raw 0..1).
Output: backend changes in five app files plus tests in four test files. No migration, no backfill.
