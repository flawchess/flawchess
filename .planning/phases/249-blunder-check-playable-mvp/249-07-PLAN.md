<objective>
Make the drill playable in the browser on top of plan 06's reducer, hook and start screen: the per-window board loop
(lead-in replay, arrow prompt "Safe / Blunder", move + reply after a correct "Safe"), the 15 s timer with server-graded
timeouts, points and forfeits with animation and sound, reload resume and stale-prompt recovery, and the session end
screen with points and Score %. A caught blunder and a missed blunder end the window with an outcome panel and a Next
button here; plan 08 inserts the better-move step and the solution screen in front of that Next, inside the same
reducer (no architectural change).

Split note (revision): this is the components half of the former single frontend plan; plan 06 holds the route gate,
wire types, client, hook, reducer and start screen. BlunderCheckTab owns the reducer and renders BlunderCheckDrill with
`state` and `dispatch`, so this plan adds components and effects without moving state.
