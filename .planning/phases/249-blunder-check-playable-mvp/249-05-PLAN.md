| client -> better-move endpoint | the client asserts a played move and its own engine tier |
| server -> client solution payload | the post-window reveal; must not leak an unreached blunder or other users' identity |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-249-15 | Tampering | better-move points farming | high | mitigate | claiming UPDATE WHERE outcome = CAUGHT AND better_move_tier IS NULL; points computed server-side from the resolved tier; second submit 409 with unchanged points (test) |
| T-249-16 | Spoofing | client_tier for an off-key move | low | accept | same residual as personalized puzzles (D-17): the key, the user's own blunder and every server-graded move are decided server-side; only an unvetted off-key move uses the browser engine's tier |

| T-249-18 | Information disclosure | foreign game_info | medium | mitigate | game_info holds time control, date and rating only; recursive test bans username/email/user_id keys |
