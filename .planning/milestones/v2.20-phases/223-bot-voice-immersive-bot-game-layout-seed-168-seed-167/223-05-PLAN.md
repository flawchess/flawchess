<objective>
Rebuild the phone game screen into the immersive shape: back arrow, bubble, board, clock
strip, and a fixed four-action bar that replaces the main nav. Retire the draw banner into
the bubble and remove the last in-game mute control.

Purpose: the mobile board width is the point of the rework (SC4), and it is won by
DELETING chrome, not by adding it. Two in-page 48px control rows and the draw-banner slot
come out; one avatar-and-bubble row goes in. Every new branch lands in a new component,
because both `BotsGame` and the shared board-control row sit exactly at their pinned
complexity ceilings and `frontend/CLAUDE.md` forbids re-baselining.

Output: the extended bar payload, four new components, a resign-only control row, the
deleted banner, and the mobile layout wired end to end.
</objective>
