<objective>
Expand the tracer to every remaining owner-scoped read on the compose / resume / complete path and cover the draw's
decisions with tests.

Purpose: research found seven sites that read a puzzle's data through the solver's user id; a missed one fails
silently (a foreign puzzle degrades to "soft, no key", is dropped on resume, or pins a session open). The tracer
converted two (answer key, solve classification). This plan converts three more (resume flaw existence, completion,
composition types), wires D-16, and proves D-01, D-02, D-05, D-06, D-14 to D-17 with tests that fail when the rule is
removed. The reveal and the facepalm badge (the last two sites) are 263-06.

Output: owner-keyed `load_session_puzzles`, `_mark_session_complete_if_done` and `_composition_puzzle_types`, the
first-ever flag on `_AssembledSessionItems`, a pure-function test module and the integration tests.

Execution note: this phase runs in a single worktree, so same-wave plans execute sequentially, never in parallel.
</objective>
