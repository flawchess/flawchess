<assumption_delta_decision>
The assumption-delta detector fired (pluralization cue "fallback" in the ROADMAP section). Re-read of the scope: the
change that matters is not the number of puzzle sources (the retired lichess filler is replaced, so there are still
three servable sources) but the assumption that a `drill_solves` row's `game_flaws` / `game_positions` rows are keyed
by the solver. A foreign blunder's rows belong to the game's owner.

- Primary noun: the game owner (`games.user_id`) is the key for a puzzle's flaw and position rows; the solver id is the
  access scope only (every read keeps `DrillSolve.user_id == user_id` in its WHERE).
- Decision: promote. Every site that reads a puzzle's blob or game move joins `games` and keys `game_flaws` /
  `game_positions` on `Game.user_id`, gated on `DrillSolve.source IN (SR_ITEM, FOREIGN_BLUNDER)`, instead of adding a
  second aliased foreign join next to a solver-keyed SR join. For an SR row the game owner is the solver by
  construction (SR rows come from `pool_entry_stmt` / `drill_items`, both owner-scoped), so SR results do not change;
  a herring row no longer joins a flaw row at all (its blob was already discarded by source gating).
- Invariant test (accepted): every converted site gets a foreign test that fails when its join is put back on the
  solver (this plan: answer key and solve classification; 263-03: resume, completion, composition types; 263-06:
  reveal and facepalm).
