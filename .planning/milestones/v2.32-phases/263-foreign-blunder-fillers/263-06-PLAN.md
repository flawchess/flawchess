<objective>
Server side of the foreign reveal (D-09, D-10, D-20, D-21), the last two of the seven owner-scoped sites
(`reveal_for_puzzle`, `_game_move_is_facepalm`).

Purpose: the reveal is the only endpoint that reads a stranger's game after the solve. It must show the blunder that
was played without claiming it as the solver's, and nothing that identifies the owner (Phase 249 D-09 rule).

Output: a FOREIGN branch in `reveal_for_puzzle` built from the already-loaded game row, `game_info` on the reveal
response, owner-keyed facepalm, and router tests over committed rows with cleanup.

Tactic line (CONTEXT discretion, resolved): the foreign reveal sends `has_tactic_lines = false`. The pointer would need
the game id, which the wire withholds (D-21), and the Train reveal's steppable lines are the client engine's Move / Best /
Game chips, which work from the FEN for any source, so the solver loses nothing.
</objective>
