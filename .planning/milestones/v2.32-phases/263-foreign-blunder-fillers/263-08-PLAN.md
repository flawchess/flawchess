<objective>
Leave the lichess filler history rows inert and delete the rest of the serving path (D-03), the second half of the
former single deletion plan.

the static set. This plan replaces every such branch with legacy-only handling (prod: 153 open sessions hold unsolved
filler rows, 14 with only fillers left; orchestrator ruling 3), renames value 2, then deletes the CSV, the service, the
generator and their tests. Task 1 changes the application and the tests that read the set in one commit, so the suite
stays green; Task 2 deletes the now-unused files and the last filler parameter. The untouched-session migration delete
and the lazy completion on resume are 263-09.

Output: legacy-only handling with its own test module, the renamed enum member, the deleted files.

Execution note: this phase runs in a single worktree; plans execute one at a time.
</objective>
