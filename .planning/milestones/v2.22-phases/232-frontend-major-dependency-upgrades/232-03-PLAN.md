- node_modules/@sentry/core/build/types/types/datacollection.d.ts: `type CollectBehavior = boolean | { allow: string[] } | { deny: string[] }`; `interface DataCollection { userInfo?: boolean; cookies?: CollectBehavior; httpHeaders?: CollectBehavior | { request?: CollectBehavior; response?: CollectBehavior }; httpBodies?: ('incomingRequest'|'outgoingRequest'|'incomingResponse'|'outgoingResponse')[]; urlQueryParams?: CollectBehavior; graphQL?; genAI?; ... }`. These are the headers v10 sent; `httpHeaders: false` would drop User-Agent and with it the browser/OS context Sentry derives (the "browser information" the Privacy page discloses). The fetch/XHR header and body capture lives in httpClientIntegration, which this app does not install.
