<objective>
Extend the Plan 01 endpoint with the session delta the score screen needs: GET /api/train/leaderboard?session_id=S returns, per board, the viewer's rank without that session's solves (D-12), computed from the same snapshot, scoped to the caller so a foreign session id changes nothing. Then prove the aggregate's scoring, filler, window and deadline rules on real rows and the hidden / guest viewer rows over HTTP.

Purpose: D-12's rank-change line ("Points board: #7 (up 3)") needs a before and an after taken at the same moment; doing it server-side in one request keeps it consistent and keeps SolveResponse untouched. This was the session-delta half of the original backend plan, split out so each DB-heavy executor run stays short (project memory: executor subagents die mid-run on long DB-heavy plans). It shares no file with the landing-card plan (230-03), so both run in wave 2.
Output: fetch_session_contribution, totals_without, the session_contribution / session_id keywords, the session_id query parameter, the new repository test module, and the without-session, foreign-id, validation, hidden-viewer and guest-viewer tests.
</objective>
