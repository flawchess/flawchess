<objective>
Fix SEED-170 item 3: the findability sort scores "didn't find the move" as 0, so in a winning position a
hard-to-find winning move ranks below a much worse findable one. Pull the penalty toward what the player
scores by playing a typical move at their level (V_fallback), clamped so a bad move is never promoted.

Purpose: better analysis-board suggestion ordering in winning positions. The user accepted the
reversal of Phase 159's showcase ordering (D-10e). Bot play is order-independent and must stay unchanged
(D-10d). This plan's last code commit is FINAL, used only for the report-only item-3 check.
Output: new rankScore formula and V_fallback, rewritten and added tests.
</objective>
