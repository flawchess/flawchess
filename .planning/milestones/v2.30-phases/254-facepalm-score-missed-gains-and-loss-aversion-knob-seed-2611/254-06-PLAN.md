## Branch and checkout map (binding for plans 06 to 18)

Phase branch = `gsd/phase-254-facepalm-score-missed-gains-and-loss-aversion-knob-seed-2611`. The phase ships four
releases; each is one cycle of the phase branch: opened off origin/main, squash-merged into main, deleted. Reusing the
one phase-branch name matches what `/gsd-execute-phase` does on a restart (it recreates a missing phase branch off
origin/main, or switches to an existing one), so a restarted session lands on the same branch this table names.

| Cycle | Opened by, from, when | Commits on it | Closed (squash-merged, deleted) by |
|---|---|---|---|
| R1 | execute-phase at phase start (exists now) | plans 01-05, 15, 16, plan 06 Tasks 1-2 | plan 06 Task 3 step 2 |
| R2 | orchestrator, off origin/main, after plan 06's SUMMARY is committed on main and before the next wave is dispatched (plan 06 Task 3 step 10) | plans 08, 18, 09 (with their SUMMARYs), plan 10 Tasks 1-2; plan 07 commits made before plan 10's merge | plan 10 Task 3 step 3 |

Between cycles the main checkout is on `main`. These land on main: plan 06's copy report and SUMMARY, plan 10's prod
report and SUMMARY, plan 12's SUMMARY, plan 14's SUMMARY, and any plan 07 commit made after plan 10's merge. The SUMMARY
of every executor plan inside a cycle lands on that cycle's branch and reaches main with its squash-merge.

Rules:

1. The main checkout `/home/aimfeld/Projects/Games/flawchess` is the only checkout that commits. From plan 06 Task 3
   on, executors are dispatched one at a time with isolation none (`gsd_run query dispatch-isolation --raw
   --force-isolation none` in the same call as each dispatch, project memory), so each works in the main checkout on
   the open cycle. An executor never creates, switches or deletes a branch; it asserts its precondition (`git branch
   --show-current` prints the phase branch) and halts when it fails.
2. Opening a cycle (orchestrator, idempotent): `git fetch origin main`; if `git branch --show-current` already prints
   the phase branch and `git rev-list --count HEAD..origin/main` prints 0, the cycle is open; otherwise, with the main
   checkout on main, `git status --porcelain --untracked-files=no` empty and `git rev-parse main` equal to `git
   rev-parse origin/main`, run `git switch -c gsd/phase-254-facepalm-score-missed-gains-and-loss-aversion-knob-seed-2611
   --no-track origin/main`. Anything else (another session holds the checkout, a stale local phase branch exists):
   stop and report to the owner.
3. Closing a cycle (orchestrator): `git switch main`, `git pull --ff-only origin main`, `git merge --squash <phase
   branch>`, one commit, `git branch -D <phase branch>`, `git branch --show-current` prints main, `git push origin
   main`, and `git rev-list --left-right --count main...origin/main` prints `0	0`. After every later `gsd_run query
   commit`, check `git branch --show-current` again (project memory: the commit helper has recreated a deleted phase
   branch before).
4. Orchestrator commits of plan 07 artifacts happen only while no executor is running, on the main checkout's current
   branch (rule above: the R2 cycle branch before plan 10's merge, main after it).
5. Prod-run worktree `/home/aimfeld/Projects/Games/flawchess/.claude/worktrees/phase-254-prod`: detached at the code prod
   runs (`origin/production` right after a deploy). Created in Task 3 step 3, re-pointed only in plan 11 Task 2 when no
   process runs from it, removed at the end of plan 11 Task 2. Every long prod pass (copy, pre, line) and its slice,
   status and parity reads run from it (`cd` into it first), so no branch switch or edit in the main checkout reaches a
   running pass or its relaunch after a reboot. It sits under the gitignored `.claude/worktrees/` inside the main
   checkout, so the app's dotenv lookup (which walks up from `app/core/`) finds the main checkout's env file; never copy
   or link that file. Setup after creating or re-pointing: `uv sync --group maia-inference` in it. Its runs write logs
   to `/home/aimfeld/Projects/Games/flawchess/temp/facepalm-backfill/` and reports through `--report-dir
   /home/aimfeld/Projects/Games/flawchess/reports/maia-flaws-backfill` (sampler sheets to
   `/home/aimfeld/Projects/Games/flawchess/temp/blunder-check/`), so every artifact is committed from the main checkout.
   The prod-run worktree never commits.
