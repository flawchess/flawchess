## Planning notes

- **Why this plan exists:** the checker flagged the old combined plan (17 files, ~150k tokens) as over the per-plan
  budget. The components have no screen dependency, so they ship first; plan 05 keeps the swap, the card-era removal and
  the reveal test ports, which must land together to keep the suite green (removing the cards breaks those tests).
- **Tree type:** `TrainMoveTreeList` takes `tree: TrainRevealTree`. Use plan 02's exported return type if it has one;
  otherwise declare a module-local `type TrainRevealTree = ReturnType<typeof useTrainRevealTree>` with a type-only import
  (do NOT edit `useTrainRevealTree.ts` in this plan, it belongs to plan 02). Plans 06+ read further fields of the same
  object (`moveListMarkers`, `isOffLine`, `pvLines`, `playLine`).
- **knip:** both components are imported only by tests until plan 05 mounts them; knip's default (non-production) mode
  counts test-file imports (the same reasoning plan 02 used for its hook). If knip still reports them, stop and report;
  never add knip ignores.
- **Height:** `TRAIN_MOVE_TREE_HEIGHT_CLASS` is a named constant starting at `'h-16'`, re-measured in the plan 11
  browser UAT (the only list height this phase adds).
- **Generic merge rule (D-02):** the chips render whatever `buildChipGroups` produced; copy and tests only exercise
  You = Best and You = Game (the owner fact in D-02: Best = Game cannot occur).
- Spec-less probe fallback skipped this run (no requirement IDs).
