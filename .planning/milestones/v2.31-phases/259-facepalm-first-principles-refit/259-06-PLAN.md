## Branch and checkout map (binding for plans 06 to 15)

Phase branch = `gsd/phase-259-facepalm-first-principles-refit`. The phase ships three releases; each is one cycle of
the phase branch: opened off origin/main, squash-merged into main, deleted. Reusing the one name matches what
`/gsd-execute-phase` does on a restart (it recreates a missing phase branch off origin/main or switches to it).

| Cycle | Opened by, from, when | Commits on it | Closed (squash-merged, deleted) by |
|---|---|---|---|
| R1 | exists now | plans 01 to 05, plan 03's reports, plan 06 Tasks 1-2 | plan 06 Task 3 step 2 |
| SW (switch) | orchestrator, off origin/main, after plan 06's SUMMARY is on main (plan 06 Task 3 step 9) | plans 07 to 10, plan 11's reports and SUMMARY, plan 12 Task 1 | plan 12 Task 2 step 4 |
| DROP | orchestrator, off origin/main, after plan 12's SUMMARY is on main (plan 12 Task 3 step 5) | plans 13, 14, plan 15 Task 1 | plan 15 Task 3 step 2 |

Between cycles the main checkout is on `main`. These land on main: plan 06's R1 report and SUMMARY, plan 12's JIT
report and SUMMARY, plan 15's SUMMARY. Every executor plan's SUMMARY inside a cycle lands on that cycle's branch.

Rules:

1. The main checkout `/home/aimfeld/Projects/Games/flawchess` (MAIN) is the only checkout that commits. Executors are
   dispatched one at a time with isolation none (`gsd_run query dispatch-isolation --raw --force-isolation none` in the
   same call as each dispatch), so each works in MAIN on the open cycle and finds the local DB config there. An executor
   never creates, switches or deletes a branch; it asserts its precondition (`git branch --show-current` prints the
   phase branch) and halts when it fails.
2. Opening a cycle (orchestrator, idempotent): `git fetch origin main`; if `git branch --show-current` already prints the
   phase branch and `git rev-list --count HEAD..origin/main` prints 0, the cycle is open; otherwise, with MAIN on main,
   `git status --porcelain --untracked-files=no` empty and `git rev-parse main` equal to `git rev-parse origin/main`, run
   `git switch -c gsd/phase-259-facepalm-first-principles-refit --no-track origin/main`. Anything else (another session
   holds the checkout, a stale local phase branch): stop and report to the owner.
3. Closing a cycle (orchestrator): `git switch main`, `git pull --ff-only origin main`, `git merge --squash <phase branch>`,
   one commit, `git branch -D <phase branch>`, `git branch --show-current` prints main, `git push origin main`, and
   `git rev-list --left-right --count main...origin/main` prints `0	0`. After every later `gsd_run query commit`, check
   `git branch --show-current` again (the commit helper has recreated a deleted phase branch before).
4. Orchestrator commits between executor runs happen only while no executor is running, on MAIN's current branch.
5. Prod-run worktree PRODWT = `/home/aimfeld/Projects/Games/flawchess/.claude/worktrees/phase-259-prod`: detached at
   `origin/production` right after the R1 deploy (Task 3 step 3), never re-pointed while a process runs from it, removed
   in plan 11 Task 2 once the reply pass is done. The line pass, the reply pass and their status reads run from it, so no
   branch switch or edit in MAIN reaches a running pass or its relaunch. It sits under the gitignored
   `.claude/worktrees/`, so the app's dotenv lookup walks up to MAIN's env file; never copy or read that file. If a run
   from PRODWT fails with a password error, run it as `cd MAIN && PRODWT/.venv/bin/python PRODWT/scripts/<script>.py ...`
   (cwd at MAIN, code and interpreter from PRODWT). Setup after creating it: `cd PRODWT && uv sync --group maia-inference`.
   Logs go to `MAIN/temp/facepalm-backfill/`, reports through `--report-dir MAIN/reports/maia-flaws-backfill`; PRODWT
   never commits.
6. One operator run at a time on prod (D-11): before any launch, `pgrep -af "backfill_maia_flaws|blunder_check_calibration|facepalm_features|build_facepalm_inputs_index|repair_short_lines"`
   prints nothing besides the run being resumed, S1 is recorded, and the sum of operator connections stays under about 25.
