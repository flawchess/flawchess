<objective>
Make the key-move term follow the type rule (D-04) in both score twins, in the fit tool and in the two status counters
that mirror the gate.

Purpose: today any loss above zero swaps the best-move term for the reply term, so blunders typed missed win are scored on
the reply. After this plan the type and the gate are one condition. The coefficients stay the Phase 259 ones until plan 07;
a gate change is a constants-style deploy with no UPDATE pass (254 D-01).

Output: `is_allowed_loss` / `_allowed_loss_sql`, both twins on it, the fit's `--gate` flag (type by default, loss for the
Phase 259 history and the D-05 reference of plan 03), the features and backfill status followers, tests.

Spec-less probe fallback: skipped (the phase has no requirement IDs to probe); recorded here as a visible choice.
</objective>
