## How this plan must be run

**Inline from the orchestrator, never in a subagent.** A `gsd-executor` dispatched on a long
DB-heavy run dies around the 40-minute mark and loses the run; anything it backgrounds dies
with it. The prod retag is projected at roughly an hour on a local DB and longer over the
tunnel. The operator pattern (from the standing project note on long operator runs):

- Launch with `setsid nohup … > <logfile> 2>&1 < /dev/null &` so the process survives the
  10-minute Bash tool cap, and record the PID.
- Poll the logfile with a monitor loop until the completion line appears; do not hold a
  foreground call open.
- To abort, SIGTERM the recorded PID (the parent holds the DB connection; workers are
  pure-CPU children).
- In zsh, a command stored in a variable is NOT word-split — wrap the launch in a shell
  function rather than expanding `$CMD`.
