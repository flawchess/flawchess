## Decisions recorded by this plan

- **D-03: nothing is paused.** Per stage: `seed` / `calibrate` / `screen` / `orphans` only
  read the cache and write audit rows; `confirm` overwrites cache rows the tick never
  overwrites (release-1 first-write-wins); `propagate` rewrites `game_positions` rows of
  long-completed carrier games the drain is not holding; `rederive` is the only stage
  touching rows a concurrent lane may also touch, and plan 03 closed that with the advisory
  lock on both sides. The lotteries and the remote fleet keep running.
- **D-05: strict stage gating and an id-ASC walk.** No pipelining of `confirm` behind a
  still-walking `screen`; the at-most-one-day saving is not worth breaking the
  re-run-after-a-kill and per-stage-timing properties.
- **Long runs are never backgrounded by an agent.** A backgrounded multi-hour run dies with
  the agent session and produces zero measurement. Every engine stage below runs in the
  operator's own terminal.
- **If `legacy-sample` returns BUILD**, `screen --legacy-cohort` becomes a follow-up phase
  proposal recorded in this plan's summary — it is not absorbed into this phase unplanned.
