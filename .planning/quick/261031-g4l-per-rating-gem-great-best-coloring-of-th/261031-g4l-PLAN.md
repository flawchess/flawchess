# Quick 261031-g4l: per-rating gem/great/best coloring of the best-move line

## Goal

In the Maia "Moves by Rating" chart, the engine-best move's line is colored per ELO
rung by the Maia-probability thresholds instead of one fixed color, when the move is
the only good move (C2). Decided in /gsd-explore 2026-10-31: the chart answers "at
this rating", so the color at the dashed selected-ELO line may differ from the
game-rung gem/great badge. No override to match the badge. Faint 30%/70% reference
lines are out of scope.

Key fact: C2 (`bestEs - secondBestEs >= MISTAKE_DROP`) is rating-independent and C1
is a flat cutoff on the line's own y value, so the per-rung tier is a pure function
of y: `<= 0.3` gem, `(0.3, 0.7]` great, `> 0.7` best.

## Tasks

### Task 1: tier helpers in gemMove.ts
- `rareTierForProbability(prob): 'gem' | 'great' | 'best'` using GEM_MAIA_MAX_PROB / GREAT_MAIA_MAX_PROB.
- `onlyGoodMoveSan(qualityBySan, bestSan, mover): string | null` — returns bestSan when
  its quality is already gem/great (stored backend tier, authoritative for C2) OR the
  live C2 gate holds (summarizeForGem argmax === bestSan and gap >= MISTAKE_DROP).
- Unit tests for both.
- verify: `cd frontend && npx vitest run src/lib/__tests__/gemMove.test.ts`

### Task 2: chart rendering
- New `MovesByRatingChart` prop `tieredSan: string | null` (optional, default null).
- Line stroke for tieredSan = `url(#gradient)`: vertical `userSpaceOnUse` linearGradient
  from `yScale(0.7)` to `yScale(0.3)` with hard stops (green above, blue between,
  violet below), drawn by an in-chart component using `useYAxisScale`.
- End label for tieredSan colored by the tier of its last-rung value.
- Tooltip: tieredSan row (and FlawChess pinned row when it is tieredSan) uses the hovered
  rung's tier for icon, word and color. Row colors derive from the per-rung quality, not
  the payload stroke (which is a `url(...)` for the tiered line).
- MaiaHumanPanel computes `onlyGoodMoveSan(qualityBySan, bestSan, mover)` and passes it;
  popover gains one sentence explaining per-rating gem/great coloring.
- verify: `cd frontend && npx vitest run src/components/analysis/__tests__/MovesByRatingChart.test.tsx src/components/analysis/__tests__/MaiaHumanPanel.test.tsx`
