# Quick 260927-b05: Replace Endgames Insights hero card with a Shelly the Turtle bubble

Decisions were locked in a `/gsd-explore` session with the user (2026-09-27):

1. Every no-report state of `EndgameInsightsBlock` (idle, pending, error, blocked) renders as a
   `TrainBotBubble` hosted by the fixed persona Shelly the Turtle (`wall-1200`), `avatarSize="large"`,
   `state="prompt"`, with the action in the bubble's `actions` slot. No card around it (the /train and
   /bots hosts sit directly on the page).
   - Idle: Shelly pitches the feature (player profile, endgame data analysis, recommendations, via an
     LLM) + Generate Insights (keeps the red first-use dot).
   - Pending: Shelly says it takes about 30 seconds; the button shows a spinner and is disabled. The
     skeleton card is removed.
   - Error: Shelly says something went wrong + Try again, gated by `blockedReason` (FLAWCHESS-AG).
   - Blocked: the three `getBlockedReason` reasons become Shelly lines inside the bubble; the button
     stays visible but disabled; no hover tooltip.
2. When a report is rendered, the bubble is hidden and only the report card shows (Insights accordion
   header, three sections, study/puzzle links, Regenerate with inline spinner). Error still outranks a
   rendered report, as today.
3. Out of scope: `OpeningInsightsBlock`.
