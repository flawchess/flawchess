# Quick 260926-9bg: Return logged-out users to their intended page

**Why:** Prod 2026-09-25 spike (GM Noel's newsletter linked flawchess.com/train directly). A logged-out visit to any protected route renders `<Navigate to="/login" />` (App.tsx ProtectedLayout), a bare form with no guest option and no return path: ~30 sessions died on the instant /train→/login bounce (66 of 137 /login sessions never progressed). Every post-auth flow (guest start in Home, LoginForm, RegisterForm, OAuthCallbackPage, AuthPage already-authed) navigates to `/`, whose authenticated branch sends zero-game accounts to /library/import, so the /train or /bots intent is lost even when signup succeeds.

**Design (deviation from the "?next= query param" sketch, same behavior):** store the intended path in `sessionStorage` instead of threading `?next=` through every link and the Google round-trip. All post-auth flows already converge on `/`, so one read site in `HomePage` covers guest start, email login/register and Google OAuth with no per-form changes. sessionStorage is tab-scoped, so a stale intent dies with the tab.

- Stash sites: ProtectedLayout no-token branch (then redirect to `/`, not `/login`), and the axios 401 interceptor before its hard redirect to /login (expired session, e.g. a Train reminder push), so returning users also come back to the page.
- Read site: `HomePage` authenticated branch, `returnTo ?? (hasGames ? '/library/games' : '/library/import')`. Read is non-destructive (render may run twice under StrictMode).
- Clear site: ProtectedLayout with a token clears the stash in an effect, i.e. the intent is fulfilled once any authenticated protected page renders.
- Sanitize on read and write: must start with `/`, not `//` or `/\`, and must not target `/`, `/login` or `/auth/*`. Anything else is ignored (no open redirect).

Accepted trade-offs: a user who explicitly logged out (no token) and then opens /train sees home first (one extra click to log in); logging out from a page and logging back in within the same tab returns there.
