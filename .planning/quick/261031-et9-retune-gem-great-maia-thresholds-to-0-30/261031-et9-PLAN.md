# Quick 261031-et9: Retune gem/great Maia thresholds (0.30 / 0.70)

Decided in /gsd-explore 2026-10-31 from prod data (1.02M games, 2.04M player-games,
C2 margin 0.10 held fixed):

| | before | after |
|---|---|---|
| GEM_MAIA_MAX_PROB | 0.20 | 0.30 |
| GREAT_MAIA_MAX_PROB | 0.50 | 0.70 |
| gems / player-game | 0.051 (4.8% of player-games >=1) | 0.103 (9.2%) |
| greats / player-game | 0.21 (17.7%) | 0.44 |

Algorithmic (chess.com-style) great rejected: C2 (only-good-move) already is the
algorithmic core; Maia is the better "not obvious" filter than recapture/check rules,
and hand rules would need new board-feature columns + backfill. Query-time
classification, so no re-analysis or backfill.
