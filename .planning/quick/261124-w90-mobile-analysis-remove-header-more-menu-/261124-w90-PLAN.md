# Goal

Give the /analysis tab panel about 57px more height on phones (<768px) without losing settings, the PGN/FEN tools or a visible way out.

# Tasks

1. **More menu.** New `frontend/src/components/analysis/AnalysisMoreMenu.tsx`: labelled column (vertical dots, "More") with an upward dropdown. Top to bottom: Leave analysis, separator, Import PGN/FEN, Copy PGN, Copy FEN, Settings (SettingsSheet in place), Flip board. Leave goes back one in-app entry, or to /library when there is none. Existing event names stay; add panel target `analysis-more`. `AnalysisTabs.tsx`: extract the PGN/FEN items so both menus share them, drop `iconOnly`.
2. **Layout.** `Analysis.tsx`: mobile footer renders the menu in BoardControls' end slot and omits `onFlip`; `pt-safe` on the mobile root; no PGN/FEN icon under the SF bar. `App.tsx`: AnalysisMobileHeader only from md to lg.
3. **Tests and CHANGELOG.**

# Unchanged

Wider layouts, Openings, Train, Bots.

# Verify

`npm run lint && npm run build && npm test -- --run && npm run knip` in `frontend`, plus a browser check at phone and 768px+ widths.
