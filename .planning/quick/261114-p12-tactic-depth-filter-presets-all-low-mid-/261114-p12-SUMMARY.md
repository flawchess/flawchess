# Quick 261114-p12 Summary

Executed inline by the orchestrator (no planner/executor subagents; the change was a handful of edits).

## What changed

- **Tactic Depth filter**: presets are now All (default, 1-12), Low (1-2), Mid (3-6), High (7-12), disjoint and inclusive. Stored 0-based: {0,11}, {0,1}, {2,5}, {6,11}. The preset key `medium` is now `mid` (also the Umami `filter-change` value for `tactic-depth`); the default key is `all` instead of `high`. The default range {0,11} is unchanged, so persisted filter state and the modified-dot logic are unaffected.
- **Facepalm Score filter**: the upper handle is displayed and sent as it reads (a multiple of 5, inclusive) instead of handle + 4. `displayUpper` removed. Presets: Low 0-30%, Mid 30-70%, High 70-100%.
- **"Mistakes are excluded" hint removed** (owner request mid-run, layout jump). The unused `hint` prop was removed from `PresetRangeFilter`. The info popover still states that a narrowed range shows blunders only.
- CHANGELOG `[Unreleased]` updated.

## Decision to confirm

With inclusive bounds on multiples of 5, neighbouring Facepalm presets share their boundary percent: a blunder showing 30% is in both Low and Mid, 70% in both Mid and High. The alternative (Low 0-25, Mid 30-65) would leave 26-29% and 66-69% in no preset.

## Verification

`npm run lint`, `npm run build`, `npm test -- --run` (365 files, 6333 tests) and `npm run knip` all pass. No backend change; backend bounds were already inclusive. Not checked in a browser.
