# Quick 261009-kb2: Maia OOM Sentry telemetry (SEED-195 step 1)

Add data to every Maia worker failure capture, so the Mac Safari wasm OOM (FLAWCHESS-CP/B2) can
be checked against the theory that too many engine workers are holding wasm memory. The goal is
telemetry only, with no behavior change.

## Task 1: live Stockfish worker counter

- files: `frontend/src/lib/engine/liveEngineWorkers.ts` (new), `frontend/src/lib/engine/stockfishWorkerSource.ts`,
  the four `createStockfishWorker` callers (`workerPoolLifecycle.ts`, `useStockfishEngine.ts`,
  `useStockfishGradingEngine.ts`, `useTrainGradingEngine.ts`), `stockfishWorkerSource.test.ts`
- action: `createStockfishWorker(sharedUrl, role)` takes a required `StockfishWorkerRole`
  (`pool` | `single` | `grading` | `train-grading`) and registers each real Worker with
  `trackStockfishWorker()`. That increments a per-role count and wraps the instance's
  `terminate()` to decrement it exactly once. `readLiveEngineWorkers()` returns per-role counts
  plus a total. Hook tests mock the factory, so they're unaffected.
- verify: new `liveEngineWorkers.test.ts` (count up, decrement on terminate, double-terminate is
  idempotent, per-role breakdown). Existing stockfishWorkerSource tests still pass.

## Task 2: Maia spawn path + attach both to the capture

- files: `frontend/src/lib/maiaWorkerErrors.ts`, `frontend/src/lib/engine/maiaWorkerHost.ts`, `maiaWorkerErrors.test.ts`
- action: add `MaiaSpawnPath` (`webgpu` | `auto-wasm` | `webgpu-failed-wasm` | `ios-wasm`), set
  per worker in `constructWorker` (passed by each spawn branch) and reset on host reset.
  `captureMaiaWorkerError` takes an optional `spawnPath`, adds the `maia_spawn_path` tag, and adds
  `contexts.engine_workers` = `readLiveEngineWorkers()`. Classification and message stay unchanged,
  so Sentry grouping is unaffected.
- verify: maiaWorkerErrors tests assert the new tag + context. The maiaWorkerHost suite stays green.

## Task 3: gate

`npm run lint && npm run build && npm test -- --run && npm run knip` (frontend only).
