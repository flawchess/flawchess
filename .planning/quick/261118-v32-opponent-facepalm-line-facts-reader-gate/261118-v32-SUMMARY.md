# Quick 261118-v32: Opponent facepalm line facts, reader gate first

Facepalm readers are gated to the game owner's side, then the scorer writes the four line facts for opponent blunders (full mode and the Maia-free line pass), so opponent blunders score in `facepalm_expr` while every user-facing selection and display is unchanged.
